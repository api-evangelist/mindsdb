# MindsDB

> MindsDB is an open-source (MIT) AI data platform and semantic query engine that lets AI agents securely query data from any datasource using SQL. It connects to 200+ data sources, builds knowledge bases and AI agents, and exposes everything over a SQL/HTTP REST API and a first-party MCP server. The company now operates as MindsHub (mindshub.ai), a unified AI workspace built on the MindsDB engine.

Generated by the API Evangelist enrichment pipeline from the API Evangelist catalog and MindsDB's public sources. Not an official MindsDB document.

## APIs

- [MindsDB HTTP REST API](https://docs.mindsdb.com/rest/overview): SQL-over-HTTP query engine plus RESTful resources for projects, databases, knowledge bases, tables, files, jobs, and agents. Self-hosted default http://127.0.0.1:47334.
- [MindsDB MCP API](https://docs.mindsdb.com/mcp/overview): First-party Model Context Protocol server (FastMCP, streamable-http) exposing a `query` tool to MCP clients (Claude, OpenAI, Cursor).

## SDKs

- [Python SDK (mindsdb-sdk)](https://pypi.org/project/mindsdb-sdk/): pip install mindsdb-sdk (official).
- [JavaScript SDK (mindsdb-js-sdk)](https://www.npmjs.com/package/mindsdb-js-sdk): npm install mindsdb-js-sdk (official).
